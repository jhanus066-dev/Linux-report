# Linux-report
Jednoduchý Bash skript pro získávání základních informací o systému Linux.

## Funkce
- Název počítače
- Informace o systému a jádře Linuxu
- Informace o procesoru
- Využití operační paměti RAM
- Využití diskového prostoru
- Síťová rozhraní
- Posledních pět záznamů o přihlášení

  ## Použití

  Spouštění skriptu v terminálu:

```bash
chmod +x report.sh
./report.sh
```
## Cíl projektu
Tento projekt vznikl při mém učení Linuxu a skriptování v Bash.

## Použité technologie
- Linux
- Bash
- Terminálové nástroje
